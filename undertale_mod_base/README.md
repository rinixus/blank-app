# Mod base: **Edu Laranja** (Undertale fan mod)

Este pacote é um **código base** para você começar um mod estilo Undertale com:

- Aparição observadora (tipo "Herobrine").
- Personagem principal: **Edu Laranja** (vibe triangular/misteriosa).
- Fantasma acompanhante.
- Diálogos sobre o submundo.
- Cutscenes com personagens de Undertale.
- Referência a **"Homem Branco"** (sem citar nome real).

> Projeto de fã, sem uso comercial. Undertale pertence ao criador original.

## Estrutura

- `game_maker/` → Base em GML (GameMaker).
- `mod_engine/` → Base em JSON para engines de mod com eventos.

## Como usar (resumo)

1. Copie os scripts da pasta desejada.
2. Substitua sprites/sons pelos seus arquivos.
3. Edite os diálogos em `dialogues_edu_laranja.json`.
4. Acione a cutscene via trigger de sala/área.

## Fluxo narrativo sugerido

1. O jogador entra em uma área escura.
2. Edu Laranja aparece por 1 segundo e some (observação).
3. Mais à frente, aparece com o fantasma.
4. Inicia diálogo sobre o submundo.
5. Cutscene curta com personagens de Undertale reagindo.
6. Edu cita “Homem Branco” e deixa mistério.
